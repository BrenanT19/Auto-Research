name: Sparse canonical profile rules
description: Product requirements for real vehicle profiles alongside the preserved demo catalog.
---

Real canonical identities must remain discoverable when optional research is missing. Expose Unknown, Not Yet Researched, and Not Applicable distinctly; never fill real profiles with demo facts or require a numeric reliability score.

**Why:** The user approved the Stage 2B approach and explicitly made truthful sparse profiles a requirement for the canonical API plan. Missing research is not evidence of a missing vehicle.

**How to apply:** Keep identity eligibility separate from optional claim eligibility. Preserve all 13 demo identities, saved links, classifications, and existing research flows. Plan only the necessary read-model, contract, and consumer safety changes; pilot data collection and UI redesign require separate authorization.
