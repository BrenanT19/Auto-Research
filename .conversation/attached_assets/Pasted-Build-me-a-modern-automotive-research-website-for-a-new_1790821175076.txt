Build me a modern automotive research website for a new business. The purpose of the website is to help people research cars before buying them by showing reliability, common problems, maintenance costs, repair costs, expected ownership costs, specifications, and other useful ownership information.

For the first version, focus on American vehicle brands, including Ford, Chevrolet, Cadillac, Lincoln, Buick, GMC, Dodge, Chrysler, Jeep, Ram, and Tesla. Later I want to expand the database to Japanese, German, Korean, and other manufacturers, so design the website and database structure so that many more brands, models, generations, model years, trims, engines, and transmissions can easily be added.

Create a clean, modern automotive design that feels professional and trustworthy rather than looking like a dealership website.

The homepage should have a large headline such as “Know the Car Before You Buy It.” Underneath, explain that users can research the real cost and reliability of owning a vehicle.

Put a large vehicle search tool near the top of the homepage where users can select or search by Year, Make, Model, and Trim.

Add sections on the homepage for:

Browse by manufacturer
Popular vehicles
Most researched vehicles
Vehicle comparisons
Reliability information
Ownership cost information
Each individual vehicle page should be organized into clear sections showing:

Vehicle overview
Model year and generation
Available engines
Available transmissions
Trim levels
Reliability information
Common problems
Typical mileage at which problems may occur
Estimated repair costs
Routine maintenance costs
Estimated annual maintenance and repair cost
Fuel economy
Estimated annual fuel cost
Insurance cost section
Depreciation
Recalls
Safety information
Expected lifespan/high-mileage information
What to inspect before buying a used example
Owner reviews and owner-reported problems
Create a comparison feature that eventually allows users to compare multiple vehicles side-by-side for reliability, ownership costs, fuel economy, maintenance, specifications, and common problems.

Create a Cost of Ownership Calculator where a user can eventually enter purchase price, down payment, interest rate, loan term, annual mileage, fuel price, insurance cost, and estimated maintenance to calculate estimated monthly and yearly ownership costs.

Add navigation for Home, Browse Cars, Compare, Ownership Calculator, Community, and About.

For now, use sample/demo vehicle data so the interface works. Clearly identify demo or estimated information instead of presenting invented data as factual information.

Build the underlying structure so real automotive data can replace the sample data later without redesigning the entire website.

Make the website mobile-friendly and responsive.

Use cards, vehicle photos/placeholders, charts or visual indicators where appropriate, but keep the interface uncluttered.

Do not build this as a simple blog. I want it structured as a scalable automotive database and research platform that could eventually contain thousands of makes, models, years, trims, engines, owner reports, and cost records.

Start by building a polished MVP with the homepage, vehicle browsing/search interface, one example manufacturer page, several example vehicle pages, vehicle comparison page, and ownership cost calculator. Make all navigation functional.
