Private U.S. Automotive Catalog Release-Readiness Review

Research date: 2026-10-08 Depth: Deep Sources consulted: 31 unique external URLs, with saved evidence in research/sources/

Executive Summary

The private development catalog contains 4,715 distinct profiles: 4,672 model-year identities and 43 trim/configuration previews. The linked records are substantially cross-checked within their stated source systems, but source matching is not the same as market completeness, exact retail configuration, reuse permission, or release approval. This review clears no profile for public release. The row-level file records release_ready_now=No for all 4,715 profiles and keeps owner approval separate from evidence status. Profile census and source checks · Row-level dispositions

A 4,099-profile group (3,605 non-2027 EPA all-years profiles, 488 annual-guide profiles, and six vPIC supplements) is the most practical cohort for any later, separately approved review. It is only a candidate review order: EPA dataset provenance and terms still need confirmation, and a vPIC listing is not a U.S. sales census. The remaining 616 profiles are on explicit hold: 539 selected historical identities, 34 preliminary MY2027 identities, and 43 trim/configuration previews. EPA download scope [1] [2] [3] [4] [5]

The most important unresolved release risks are source-specific terms for exact trim sources, missing revision-level provenance and independent checks for Wikipedia-derived history, and the mismatch between the all-years EPA file description and separately published preliminary 2027 files. Checksum correction: the extracted EPA CSV matches the catalog checksum; the earlier ZIP-to-CSV comparison was incorrect. No production data, release settings, or public visibility were changed. This is a private source-readiness assessment, not legal advice or approval to publish.

Key Findings

1. Linked EPA and annual-guide rows match their source records, but that does not clear the dataset for release

The 3,639 EPA all-years profiles have 18,764 referenced vehicle rows that matched the live file retrieved on 2026-10-08 for ID, make, model year, source model label, and base-model grouping. The extracted CSV checksum exactly matches the stored source hash; the earlier comparison incorrectly used the ZIP checksum against a CSV checksum. The separate 488 MY1978–1983 guide profiles match six file checksums and all 908 recorded line locators. These checks establish traceability to EPA fuel-economy records, not every vehicle sold in the United States or a complete retail lineup. Detailed row checks [1] [6] [7] [8]

EPA's standard statement says EPA-produced data are public domain by default unless otherwise specified and directs users to the associated dataset metadata for limitations, restrictions, and intended use. FuelEconomy.gov describes its data as coming from EPA testing and manufacturer testing under EPA oversight. That makes the general EPA statement favorable for EPA-produced material, but it does not by itself settle provenance or third-party rights for every field in every export. For the current candidate cohort, confirm the relevant dataset metadata and preserve the file version and retrieval date. [2] [9] [1] [3]

2. vPIC corroborates six identities, with a public-use statement but a limited data scope

The six NHTSA/vPIC supplements match results from five current year-scoped queries: one Ram MY2024 query contains both Ram 2500 and Ram 3500 labels, and four Tesla queries each return the Roadster for MY2008–2011. The saved responses and exact URLs establish what the queried vPIC endpoints returned; the Ram response's 112 rows do not turn it into a sales count. Exact query audit [10] [11] [12] [13] [14]

NHTSA's vPIC FAQ says the API is free for public use without licensing or application registration, while also asking users to schedule large batches considerately. Its separate API-use policy specifically cautions against other applications performing bulk VIN lookups and describes traffic controls for such requests. This review used make/model/year listing endpoints, not bulk VIN decoding. The FAQ also describes gaps where manufacturers have not submitted information and lower confidence in older VIN-era data. Therefore vPIC is useful corroboration for these six queried records, not evidence that an absent make/model/year was never sold or that the catalog is complete. [5] [15] [4] [16] [17]

3. MY2027 has a distinct preliminary-source and identity-crosswalk issue

FuelEconomy.gov labels the all-years download as MY1984–2026 and lists a separate MY2027 datafile and “2027 Guide (Preliminary).” The profile audit reports that all 34 catalog MY2027 IDs match the current all-years ZIP, but the profile source ID does not distinguish that file from the separately published preliminary workbook. The workbook contains 363 MY2027 rows; a conservative make/division plus model/carline name-only comparison found 21 of the 34 catalog profiles and did not find 13. The workbook's EPA label dataset IDs could not be joined directly to the catalog's vehicle-ID locators. EPA download page [1] [18] [6] · Saved crosswalk and unmatched names

A name match is not an exact vehicle-ID match, a finalized retail lineup, or proof of sale. A missing name in this preliminary guide is not proof that a vehicle was unavailable. Keep all 34 MY2027 profiles on hold until their exact source lineage, model-year status, and U.S. availability are resolved or the rows are excluded from any release. [1] [18] [7]

4. The 539 historical identities remain selected secondary evidence, not verified U.S. history

The 539 historical profiles are linked to selected secondary references; 533 are before MY1978 and six fall in MY1978–1983. This pass did not independently verify each year-specific identity against a comprehensive archive. EPA's test-car archive covers defined fuel-economy program material; GM's Heritage collections and The Henry Ford's production-record holdings are valuable but bounded collections. Their existence helps locate individual evidence and does not establish all-make, year-by-year coverage. The 660 within-name gaps remain leads, not confirmed omissions or hiatuses. Historical and gap limits [8] [6] [19] [20] [21]

The source inventory's internal allowed labels do not resolve revision-level terms for Wikipedia-derived material. Wikipedia's reuse guidance points to attribution and share-alike terms, and the CC BY-SA 4.0 legal code includes attribution/share-alike requirements and conditional database-rights provisions. The exact article revisions, attribution records, and applicability to this normalized catalog were not established here. U.S. Copyright Office guidance on unprotected works is relevant to factual material, but it is not a determination about a particular source collection or website's access terms. Keep these profiles on hold until revision provenance, attribution, and a use-specific assessment are complete. [22] [23] [24] [9]

5. All 43 trim previews need source- and configuration-specific clearance

The 43 preview profiles carry 237 accepted evidence rows across 26 exact URLs; 235 rows are marked moderate strength and two strong. Each preview has at least two linked URLs. These are internal evidence counts, not a complete trim catalog, legal clearance, or proof that a source supports every cab, bed, engine, drivetrain, package, and U.S. retail combination. The row-level claims and URL grouping are available in the trim evidence export and source ledger.

The unresolved source groups are specific. Twenty GM profiles cite content on separate GM media portals or PDF files; GM's corporate copyright page addresses materials “on this website” and does not itself set terms for those other hosts. Six Ford F-150 previews cite an Auto-Brochures-hosted PDF that lists six trim levels, while the site's ownership and applicable use terms remain unresolved. Ford.com terms allow only limited personal, non-commercial use of Ford.com materials and expressly warn that other Ford sites may have different terms; a separate Ford editorial-use page is also a different host from the target media/manual files. Twelve Ram previews cite FCA/Stellantis materials with editorial-use restrictions, while the separate S3-hosted matrix's own terms remain unresolved. Four Lucid previews lack IR-specific reuse terms, and the one Mustang preview combines preliminary technical evidence with sources that do not prove exact retail trim/body. These are source-specific holds, not a conclusion that factual vehicle names always require manufacturer permission. [25] [26] [27] [28] [29] [30] [31] [24]

The direct terms pages are first-party evidence about the named sites, not independent legal opinions and not blanket terms for sibling hosts, linked PDFs, facts, or automated retention. The saved snippet notes state the boundaries and what the search did not establish; unresolved items should remain unresolved rather than being treated as permission. Search and scope notes [25] [26] [28] [29]

Analysis

The audit supports a useful distinction between source verification and release readiness. EPA and vPIC profile rows can match the identifiers or labels returned by their source systems while still leaving open whether those systems enumerate all U.S. retail vehicles and whether source-specific conditions apply to the intended use. The exact EPA CSV payload is now confirmed by a like-for-like checksum comparison. Annual guide locators similarly establish traceable rows, not a complete national sales list. The row-level CSV uses conditional cohort labels rather than marking profiles release-ready; it now includes the corrected checksum result and the owner's later verification-then-publication instruction. Corrected audit [1] [2] [6] [4] [5]

A later narrowly scoped release review could begin with the 4,099 rows that have the strongest source-link verification, but not with an automatic publication. Before that step, decide what fields will be displayed, inspect the relevant dataset metadata and source-specific reuse conditions, retain exact provenance/version information, and label the collection as non-exhaustive. The 539 historical profiles, 34 MY2027 profiles, and 43 trim previews need distinct evidence paths rather than a single “catalog verified” badge. Those distinctions prevent a high-quality record match from implying complete market coverage or exact retail configuration. [3] [6] [16] [8] [18]

The trim review is the clearest example of why rights and identity cannot be collapsed. A source can state a trim name without proving all compatible configurations; a searchable PDF can support a factual claim without granting a right to republish the page or image; and a terms page for one corporate host may not govern the media portal or third-party file actually used. The same precision is needed for historical rows: the fact that a vehicle existed and the rights/attribution conditions of the selected source are separate questions. The report preserves these unresolved items at the cohort level and the CSV carries the corresponding disposition per profile. [25] [26] [29] [31] [22]

Limitations

This review did not reconstruct all U.S. vehicle sales, independently validate all 539 historical facts, or establish exact 2027 retail availability. The 2027 join is name-only, not an EPA vehicle-ID reconciliation. The prior EPA checksum concern is resolved: the extracted CSV matches the stored source hash. The 26 trim URLs have an internal source ledger, but several exact publisher hosts and standalone files have no confirmed access, storage, attribution, automation, or display terms. The report gives source-use triage, not a legal opinion. The 660 year-gap leads remain unresolved. This earlier review itself did not authorize publication. The owner's subsequent request is conditional: verify every profile and its information before preparing publication.

Recommendations

  1. Keep all 4,715 profiles private for now. The row-level file marks every profile release_ready_now=No; the review itself did not change production data or release settings.
  2. Treat 4,099 profiles only as a future review cohort. Resolve EPA dataset metadata and source-specific terms; preserve current and saved-file hashes; keep non-exhaustive language. Apply vPIC FAQ and API policy only to the scope each states, and do not describe vPIC as a sales census.
  3. Keep all 34 MY2027 rows on hold. Resolve the separate preliminary workbook's source lineage and exact vehicle IDs, or exclude those profiles from any scoped release. Do not treat the 13 name-crosswalk misses as unavailable vehicles.
  4. Keep all 539 historical rows on hold until year-specific evidence and revision-level attribution/source history are checked; otherwise omit them from the public scope.
  5. Keep all 43 trim previews on hold until exact source-host terms and retail configuration relationships are resolved or the evidence is replaced with sources cleared for the intended use.
  6. Require separate, explicit owner approval after the scope, data fields, source conditions, and public-facing coverage language are settled. This report is not that approval.
