All-profile information verification — current results

Checked: 2026-10-08 UTC / 2026-10-07 Pacific<br> Sources cited: 190<br> Status: Full factual verification is incomplete. No public release was prepared or published.

What was checked

Every one of the 4,715 distinct development profiles was retrieved, not just sampled. All profile IDs and make/model/year/trim values matched their Browse records. The census found 14,936 nonempty top-level information fields, 5,668 claim/source associations, and 97 distinct external source URLs. Empty reliability objects with null values were excluded from populated research. These are reproducible local inventory results, not a claim that all facts are verified. Inventory summary · Field-by-field inventory

The request is to verify existing information before publication. Missing research may remain clearly labeled missing; it need not be invented. A model-year identity does not require a complete retail build sheet, and a trim-name preview does not require an exhaustive option matrix unless it claims such facts. Conversely, a populated generation label, fuel specification, or factual overview needs evidence for the actual value and scope displayed.

Corrected EPA checksum finding

The earlier audit incorrectly compared the ZIP archive checksum with the catalog's extracted-CSV checksum. A fresh download's extracted vehicles.csv exactly matches the catalog hash. All 18,764 referenced vehicle rows across 3,639 profiles were rechecked, with zero ID/make/model/year/base-model mismatches. The source-version discrepancy is therefore resolved, not an outstanding release blocker. Recheck evidence The official dataset page defines its fuel-economy scope; EPA's annual-guide archive and web-services documentation provide their respective file and identifier contexts. [1] [2] [3]

EPA's default public-domain statement is favorable for EPA-produced data, subject to stated exceptions and dataset metadata. It does not create a blanket requirement for manufacturer permission merely because facts concern their products. Copyright limitations on factual material and source-specific contractual restrictions are different questions. [4] [5] vPIC's public-use FAQ and API documentation support a narrow agency-query use, not a complete national retail-sales census. [6] [7]
