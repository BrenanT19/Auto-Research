# EV makers search notes

Searches completed on 2026-10-08, before source fetches. The notes below paraphrase selected result snippets; they are not quotations. Weak, rights-unclear, calendar-year-only, and conflicting results are marked as excluded rather than relied on.

## Search 1: What primary records verify Tesla, Rivian and Lucid first U.S. model years?

- **Tesla Motors Begins Regular Production of 2008 Tesla Roadster | Tesla Investor Relations** — https://ir.tesla.com/press-release/tesla-motors-begins-regular-production-2008-tesla-roadster
  - Result gist: Tesla's contemporaneous press release explicitly identifies the 2008 Roadster model year and says reservations for MY2009 were being taken.
- **Vehicle Detail Search - 2022 Lucid Air** — https://www.nhtsa.gov/vehicle/2022/Lucid/Air
  - Result gist: NHTSA has a model-year-specific 2022 Lucid Air vehicle page; this confirms an official 2022 listing, not a sales start date.
- **Vehicle Detail Search - 2022 RIVIAN R1T | NHTSA** — https://www.nhtsa.gov/vehicle/2022/RIVIAN/R1T
  - Result gist: NHTSA has a model-year-specific 2022 R1T vehicle page; the contemporaneous MY listing is not a retail-delivery date.
- **RIVIAN AUTOMOTIVE, LLC – application for certification** — https://dis.epa.gov/otaqpub/display_file.jsp?docid=62830&flag=1
  - Result gist: EPA source lists a formal Rivian MY2026 certification application (source already retained as ev-makers-02).

## Search 2: What are vPIC limitations for exact manufacturer Make_ID history?

- **Vehicle API - Transportation** — https://vpic.nhtsa.dot.gov/api/
  - Result gist: Official API docs describe exact-ID and name-matching methods, manufacturer-submitted data, and API rate control.
- **Downloads - NHTSA vPIC - Department of Transportation** — https://vpic.nhtsa.dot.gov/Downloads
  - Result gist: Search result says the standalone database is limited to VIN decoding; other make/model data require API access.
- **NHTSA Datasets and APIs** — https://www.nhtsa.gov/nhtsa-datasets-and-apis
  - Result gist: NHTSA landing page describes the API response as model-year/make/model vehicle variants; not a comprehensive retail-sale catalog.

## Search 3: What evidence supports MY2026 and preliminary MY2027?

- **RIVIAN AUTOMOTIVE, LLC – MY2026 Part 1 application** — https://dis.epa.gov/otaqpub/display_file.jsp?docid=62830&flag=1
  - Result gist: The official EPA-submitted certification document is dated 2025-03-21 and identifies 2026 carlines, including R1T and R1S.
- **FuelEconomy.gov all-model-years vehicle data** — https://www.fueleconomy.gov/feg/epadata/vehicles.csv.zip
  - Result gist: The reviewed catalog identifies this EPA file as the source for triad MY2026 and MY2027 base-model groupings; MY2027 is expressly labeled preliminary in the snapshot limitations.
- **Tesla 2026 delivery consensus | Tesla Investor Relations** — http://ir.tesla.com/press-release/delivery-consensus-second-quarter-2026
  - Result gist: Search hit refers to calendar-year delivery projections, not 2026 model-year evidence; excluded from model-year claims.

## Search 4: Which independent rights-compatible sources verify model-year naming and hiatuses?

- **NHTSA vPIC exact-ID model/year endpoints (Tesla, Rivian, Lucid)** — https://vpic.nhtsa.dot.gov/api/vehicles/GetModelsForMakeIdYear/
  - Result gist: Independent government listings provide name/year relationships, but do not establish a complete sales chronology or prove an unlisted year was a hiatus.
- **Roadster History North America | Tesla Motors Club** — https://teslamotorsclub.com/tmc/threads/roadster-history-north-america.8599
  - Result gist: Forum result asserts a MY2009 Roadster hiatus; treated as low-tier, contradicted by Tesla's contemporaneous MY2009 reservation statement, and not used as evidence.
- **Tesla Roadster (first generation) | Wikipedia** — https://en.wikipedia.org/wiki/Tesla_Roadster_(first_generation)
  - Result gist: Search result provides a secondary timeline; excluded from final claims, which rely on linked primary/gov evidence.
