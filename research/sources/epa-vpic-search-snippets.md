# Search evidence register: EPA / vPIC scope

Searches run on 2026-10-08, before any source fetch. The short notes below paraphrase result snippets; they are discovery leads, not substitutes for reviewing each source.

## Query 1 — EPA FuelEconomy.gov year coverage

Question: What vehicle years and coverage limits does EPA FuelEconomy.gov publish?

- **Download Fuel Economy Data** — https://www.fueleconomy.gov/feg/download.shtml  
  Search result reports a downloadable all-model-year dataset for MY1984–2026; page fetch verified this and a separate preliminary MY2027 listing. [Fetched evidence: `epa-01-download-coverage.md`]
- **Compliance and Fuel Economy Data for Vehicles and Engines** — https://www.epa.gov/compliance-and-fuel-economy-data  
  EPA compliance/fuel-economy hub has distinct datasets, test records and reports; such technical material should not be equated with an all-market sales registry.
- **Fuel Economy Web Services** — https://www.fueleconomy.gov/feg/ws/index.shtml  
  Search result describes Find-a-Car table coverage as 1984-current. Useful corroboration of the public data boundary; not fetched in this pass.

## Query 2 — NHTSA vPIC model-year listings

Question: What do NHTSA vPIC model-year listings prove and not prove about U.S. retail model-year completeness?

- **NHTSA vPIC About** — https://vpic.nhtsa.dot.gov/About  
  Described as manufacturer-submitted information supporting VIN decoding and related manufacturer records, intended for MY1981-forward use; page also describes public open-data use. [Fetched evidence: `epa-02-nhtsa-vpic-scope.md`]
- **NHTSA vPIC Vehicle API** — https://vpic.nhtsa.dot.gov/api  
  Search result ties the dataset to manufacturer VIN-information submissions (49 CFR Part 565). This explains the record-generation basis, not U.S. retail-sales completeness; not fetched in this pass.
- **NHTSA vPIC Downloads** — https://vpic.nhtsa.dot.gov/Downloads  
  Search result warns that standalone downloads are VIN-decoding-only and points users to APIs for model/make and related values; not fetched in this pass.

## Query 3 — official EPA annual guides

Question: Are official EPA fuel economy guides exhaustive U.S. retail model-year lists?

- **2026 Fuel Economy Guide** — https://www.fueleconomy.gov/feg/pdfs/guides/FEG2026.pdf?pubDate=20260402  
  The guide's scope section discloses categories outside light-duty fuel-economy requirements and says some information can miss publication timing. That is affirmative evidence the guide is not an all-retail-identity census. [Fetched evidence: `epa-03-fuel-economy-guide-scope.md`]
- **2024 Fuel Economy Guide** — https://www.fueleconomy.gov/feg/pdfs/guides/FEG2024.pdf  
  Search result confirms an annual model-year guide organized for consumer fuel-economy estimates. The guide is scoped by its program, not by all vehicles sold; not fetched in this pass.

## Query 4 — checking pre-1984 identities

Question: How can historical U.S. automotive identities be checked before 1984?

- **Test Data for Annual Fuel Economy Guide** — https://www.epa.gov/compliance-and-fuel-economy-data/test-data-annual-fuel-economy-guide  
  EPA's linked annual-guide/test-data table covers model years back through MY1978. This offers a primary historical evidence series for some pre-1984 identities, but it is still fuel-economy program coverage, not a complete market census. Existing fetched evidence: `epa-04-annual-guide-test-data.md` (EPA page updated 2026-02-18).
- **Reports on Cars Used for Testing Fuel Economy** — https://www.epa.gov/compliance-and-fuel-economy-data/reports-cars-used-testing-fuel-economy  
  Search result describes detailed EPA test-car data for MY1978–1997. Test-car records can corroborate particular vehicles/configurations and years but do not show that every retail vehicle was tested; not fetched for this pass.

These discovery results deliberately exclude non-authorized publisher/aggregator sources. No absence from EPA or vPIC is treated as evidence of non-sale.
