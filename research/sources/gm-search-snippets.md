# GM history/model-year search evidence

Search evidence captured in this private research pass on 2026-10-08. The notes
below paraphrase the returned snippets; they are discovery leads, not fetched
source text or proof of model-year completeness. Tiers: 1 = government/legal
primary source; 2 = independent reference publisher; 3 = manufacturer source
(primary for its own statements, not independent verification). No permission
to reuse images, brochure text, or a bulk catalog is implied.

## Search 2 — historical make/model distinctions

- GM Heritage: An Iconic Legacy, https://www.gm.com/heritage
  - Date: not surfaced; accessed 2026-10-08. Tier 3.
  - Search summary: GM's own heritage page recounts the formation of GM and
    separately discusses Buick and Chevrolet as brands. It is corporate
    heritage context, not a historical model-year catalog.
- Pontiac | GM Heritage Collection,
  https://www.gm.com/heritage/collection/pontiac
  - Date: not surfaced; accessed 2026-10-08. Tier 3.
  - Search summary: the archive navigation exposes Buick, Cadillac, Chevrolet,
    Chevy Trucks, GMC, Oldsmobile, Pontiac, and concept collections. Collection
    labels should not be confused with a complete historical brand taxonomy.

## Search 3 — possible nameplate gaps and returns

- GM to retire Camaro at the end of the 2024 model year,
  https://news.gm.com/home.detail.html/Pages/news/us/en/2023/mar/0322-camaro.html
  - Published 2023-03-22. Tier 3.
  - Search summary: GM stated that the sixth-generation Camaro would end after
    MY2024. This does not by itself establish a later Camaro hiatus.

## Search 4 — model year versus production date

- 40 CFR Part 85 Subpart X, https://www.ecfr.gov/current/title-40/chapter-I/subchapter-C/part-85/subpart-X
  - Rule source: 60 FR 4738, 1995-01-24; current eCFR view accessed 2026-10-08.
    Tier 1.
  - Search summary: the rule defines model year using the manufacturer's annual
    production period and a January 1 calendar-year anchor; it separately
    defines production period.
